# Changelog

## 0.1.1

First release on npm: the v0.1.0 publish job ran the tests without
installing dependencies and stopped before publishing. No code changes.

## 0.1.0

First release: `HibiraProvider`, a Yjs provider for pusher-js and Laravel Echo
on private and presence channels, with awareness, sync after reconnects,
chunking of large updates and a client-side rate limit under the server's
client event limit.
